# Vennila Backend API

Express Node.js Backend API for Vennila Accessories with Firebase Firestore and Redis Cloud caching.

## Features
- **Firebase Admin SDK**: Product catalog and user management via Cloud Firestore
- **Redis Cloud Integration**: High-performance caching for fast GET queries
- **Express.js API**: Clean RESTful routes for auth, products, users, and requests

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Create `.env` based on `.env.example`.
3. Start development server:
   ```bash
   npm run dev
   ```
